## Phase 3 — A Lösung

Lane ist eine reine Funktion. Eine Karte = eine Familie (Wurzel über `parentSessionId`).

| Lane | Ableitung | Klick |
|---|---|---|
| Offen | letzte Sitzung `status !== ended`, keine Repeat-Familie | `/sitzung/{id}` |
| Denselben Moment | Repeat-Familie (`mode=repeat` oder parent oder ≥2 Glieder) | Leitung wenn Kind aktiv, sonst `/auswertung` |
| Ausgewertet | beendet, Erstversuch, nächster Übungsschritt vorhanden oder Auswertung offen | `/sitzung/{id}/auswertung` |
| Ruhend | beendet, `not_assessable` und kein nextStep/repeatPrompt | `/sitzung/{id}/auswertung` |

Leere Lanes werden nicht gerendert. Reihenfolge der Abschnitte: Offen → Denselben Moment → Ausgewertet → Ruhend (Handlung vor Inventar). Das sind A02-Worte, keine A01/A10-Aliase.

Karte: Figur, Fokus, ein Hebel aus `evaluation.nextStep` (nicht `practiceCue.lever` = Stärke/Recap). Keine Score-Galerie, kein €, kein Forecast.

B1–B4-Chip-Zeile ist aus der Hauptfläche. Musterkarte: Reading hinter `<details>`, CTA „gezielt üben“ gestrichen.

Freeze gehalten: EvaluationView, debrief-moments, ConversationView, liveCall, bargeIn, live-text, openai-realtime unangetastet.
