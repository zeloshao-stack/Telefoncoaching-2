## AUFTRAGSVERSTÄNDNIS

- Nutzerwirkung: mhm/kurz legt die Figur nicht um. Echtes Reinreden stoppt hörbar. Gehörtes = Client-Wiedergabe-Uhr dieser `generation_id`.
- Komponente: Transport/Timing. Nicht Prompt, nicht Chrome, nicht Figur.
- Nicht-Ziele: Truncate, semantic-high Default, `create_response: false`, A05-DB, ConversationView-Skin.
- Annahme: Resume ohne Provider-Pause ist lokal Mute; unsicher → Cap→B. `LIVE_STAGE_B_MIN_MS = 800` (Hume min_interruption / 006), eine Zahl.
- Akzeptanz: Prefix `interrupt_response: false`; Stufe A hält; A→B sendet cancel+clear; Uhr freeze vor Cancel; Tests grün.

## IMPACT_PLAN

- `lib/openai-realtime.ts` — server_vad Default `interrupt_response: false`; `create_response` true.
- `lib/live-text.ts` — Stufe A/B, Clock, Heard-Ack, Backchannel-Gate.
- `components/training/liveCall.ts` — Verdrahtung; GO-2 Unlock nur Stufe B.

- ConversationView unberührt.

## A06 Lösung

1. Prefix: Client ist Stufe-B-Owner. Semantic-Env unverändert (nicht Default).
2. `speech_started` während Figur spricht → Stufe A: Soft-Hold (Mute/Gain 0, kein pause, keine Track-Sperre), kein cancel/clear, gleiche `generation_id`, Phase bleibt speaking.
3. A→B: 800 ms Watchdog/Dauer **oder** Segment/Completed mehr als Backchannel `{mhm, mmh, aha, genau, ja, jo, ok, okay, hm, ähm, äh}`. Deltas akkumulieren nur (kein „m“→B).
4. Stufe B: Freeze → `applyHardPlaybackCut` → cancel+clear → Heard-Ack = Freeze. Unlock-AND nur hier; `speech_stopped` nachträglich geseedet wenn schon da.
5. Resume A: Unmute, thaw, kein `response.create`, kein Truncate. Restore unsicher oder Generation tot → kein Fake-Resume / Cap→B.
6. Uhr: `performance.now()` ab `output_audio_buffer.started`, nur hörbar, an `response.id`. Fail = `unknown`, kein Fake-0. Nutzer-`audio_end_ms` bleibt User-EOT.
7. Mic-Tracks während Barge-in nicht `stop()`.
