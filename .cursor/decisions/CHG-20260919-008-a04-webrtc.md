### H1 — Unlock-Handshake-FSM, nur Stufe B (A06-007 H3)

**Quelle:** A06-007 H3: Unlock = `speech_stopped` ∧ (`cancelled` ∨ `cleared`) ∧ kein Restton; Clear = Ohr; Cancel best-effort; Watchdog; `response.created` No-Op. A01-007 Hebel 2: generation_id ist Zwei-Phasen-Commit, nicht Client-Timer.

**Client-Besitz:** Explizite Handshake-Zustände, gebunden an `generation_id` der gekappten Äußerung — nicht ein Bool `suppressPlayback` für alles.

| Zustand | Bedeutung | Nächster |
|---|---|---|
| `cut_pending` | Stufe-B-Cut lokal, Events gesendet | warte Ack |
| `ear_clear` | `output_audio_buffer.clear` **oder** Watchdog-Stille (Clear ausgeblieben, `isBenignLiveCancelError`) | warte `speech_stopped` falls noch offen |
| `line_idle` | `speech_stopped` nach Cut **und** Ohr-Bedingung | Unlock |
| `unlocked` | Folge-`generation_id` darf spielen | — |
| `unlock_failed` | Watchdog ohne Reststille / ohne Clear-Ersatz | sichtbares Ende (H7), kein stilles Hängen |

**Nicht:** Handshake auf Stufe A (007-A04: Stufe A sendet keine cancel/clear — sonst Clear/Resume-Widerspruch). Nicht naives AND ohne Watchdog (A06-007 K06-1 Deadlock). Nicht `track.stop()` (Remote: `enabled = false`, Exit bleibt 006).

**Evidenz:** PLAUSIBEL (A06-007 + HEAD-OR-Ack). Watchdog-ms UNBEKANNT.

### H2 — `generation_id`-Phasen, kein viertes Token (A01-007)

| Phase | Wer setzt | Heard? |

| `requested` | Client sendet cancel (Stufe B) | nein |
| `ack_cancelled` | Provider `response.cancelled` / done-cancelled | nein |
| `buffer_cleared` | Provider `output_audio_buffer.clear` | nein — Ohr-Signal |
| `unlocked` | H1 `line_idle` | Heard-Ack darf jetzt für **diese** ID (oder Discard) |

`eventGeneration` (HEAD) bleibt Call-Attempt/DC. Es beerbt weder `sessionId` noch `response.id`.

**Timeout (HYPOTHESE, A01-007 Ausfall):** Unlock-Deadline. Läuft sie ab **ohne** gehörten Schlusssatz → Drop-Copy, nicht „{Name} hat aufgelegt.“ (A03-007 Idee 6). Läuft sie im Hangup-Tx nach gehörtem Schlusssatz ab → Figur-Ende, Werkzeug egal.

### H5 — Heard-Ack als State-Revision (A05-007 I2)
