## 3. Fünf Mess-Steals für Debrief-Momente

Jede Idee: Fremdmuster, Definition, Unit, Instrument, Bericht, Woche 1, Verbot. Kein Gate. Kein MOS. Kein Elo. Keine Parität. Keine fremde n-Zahl.

Nicht neu (verbraucht): Höranker-Findbarkeit (M10), Eval-Job-Schnitt (M17), C0, Face, Timing-Triade.

### D1 / M21 — Moment-Tripel-Schluss (Gong Points of Interest)

**Fremd:** Gong-Call-Page markiert Points of Interest auf der **Aufnahme** (Frage, Preis, …). Klick = Sprung. Das ist ein geschlossenes Objekt, keine Win-Rate. `010-gong.md` E.1.

**Konstrukt C14 — ein Debrief-Moment ist geschlossen oder er existiert nicht.**

Ein primärer Moment ist **geschlossen** nur wenn alle vier da sind:

1. Zeitfenster auf der Aufnahme `(t0, t1)` — nicht nur eine Textzeile
2. Zitatspanne (nichtleer, Sprecher zugewiesen)
3. genau ein Kriterium **oder** eine `not_assessable`-Begründung
4. Emission **nach** Hangup-Commit (sonst D3/SC-LIVE)

| Code | Beobachtung |
|---|---|
| MT-CLOSED | alle vier Felder |
| MT-PROXY | turnId + Zitat + Kriterium, **ohne** `t0/t1` | 
| MT-OPEN | Pflichtfeld fehlt, kein N/A |
| MT-LIVE | Moment/Score vor Hangup sichtbar |
| MT-MULTI | mehr als ein **primärer** Moment als Headline |
| MT-ABSENT | Session ended, kein Moment und kein N/A |

**Heute:** EvaluationView bindet `keyMoment.turnId` + Zitat + Fokus-Dimension. Das ist **MT-PROXY**, nicht MT-CLOSED. Timeline-ms fehlen. `instrument_missing` für Zeiten, nicht 0 % CLOSED.

**Unit:** eine Session, ein primärer Moment. `evidenceTurnIds` und Dimension-Karten sind Belege, keine Extra-Momente.

**Instrument:** Payload der Auswertung, deterministisch. Kein Annotator. Kein LLM-Judge.

**Bericht:** Zähler je Code, n Sessions. Kein „Moment-Score“.

**Woche 1:** nur Zähler auf vorhandenen `/auswertung`-Payloads. Kein Gate. Kein neuer Hörer.

**Verboten:** MT-PROXY als Gong-Parität verkaufen; MT-CLOSED-Rate als Trainee-Qualität; POI-Typen (Filler, Wettbewerb) aus Gong kopieren; mehrere Dimensionen zu MT-MULTI zählen.

### D2 / M22 — Anker-Kongruenz (Gong-Sprung × Careertrainer-Zitatpflicht)

**Fremd:** Gong: Klick auf Moment springt an diese Stelle. Careertrainer: jede Teilbewertung zitierpflichtig. Hyperbound: Kriterium → Begründung + Transkriptzitat. Nicht deren Trefferquoten.

**Konstrukt C15 — das gezeigte Zitat steht in der genannten Stelle.**

Gegen den **committed** Snapshot nach Hangup, normalisiert (Whitespace, Anführungszeichen):

| Code | Test |
|---|---|
| AK-HIT | Zitat ist Teilstring des zitierten Turns (oder des Fensters `t0–t1`, sobald vorhanden) |
| AK-DRIFT | Zitat steht woanders im Transkript, nicht am genannten Turn/Fenster |
| AK-GHOST | Zitat kommt im Snapshot nicht vor |
| AK-NA | `not_assessable` — kein Zitat gefordert |
| AK-MISSING | kein Transkript / kein Snapshot → `instrument_missing`, nicht 0 % GHOST |

**Abgrenzung M10:** M10 fragt, ob zwei **blinde Hörer** denselben pädagogischen Beat finden (DEFER, Qualität). D2 fragt, ob das **Gerät** ein Zitat erfindet. Andere Frage, anderes Gold.

**Unit:** primärer Moment plus jede **angezeigte** Stärke-/Fokus-Zitatzeile. Nicht jedes `evidenceTurnId` im Detail.

**Instrument:** Stringtest zuerst. Nur AK-DRIFT-Grenzfälle dual, AC1. Kein LLM-Judge. Keine Ähnlichkeitsschwelle „70 %“ (sähe aus wie Careertrainer-70/30).

**Bericht:** Zähler, n Zitate. Ghost-Beispiele intern, **nicht** an A07.

**Woche 1:** deterministischer Pass auf vorhandenen Auswertungen, falls Transkript im Snapshot liegt. Sonst AK-MISSING.

**Verboten:** Ghost-Rate als C0; Zitat ins Role-Player-Prompt; Fuzzy-70 als „Kongruenz“.

---

### D3 / M23 — Sichtbare Scorecard-Lage (Gong + Hyperbound post-call)

**Fremd:** Gong-Scorecard sitzt auf der Call-Page / nach Practice-Stop. Hyperbound Practice: Debrief after every call; Live-HUD ist Perform-Add-on. A00: keine Noten während der Leitung.

**Konstrukt C16 — was der Trainee als Note sieht, erscheint erst nach dem Auflegen.**

Das ist die **sichtbare Fläche**, nicht der Eval-Job (M17).

| Code | Test (Log + Route) |
|---|---|
| SC-POST | erste nutzersichtbare Score/Kriterien-Fläche nach `ended` + Snapshot |
| SC-LIVE | Score, Tick, Talk-Ratio, Filler oder Rubrik-Chip auf der Live-Route |
| SC-PREVIEW | volle Rubrik vor dem Wählen |
| SC-ABSENT | ended, keine Fläche und kein N/A-Satz |
| SC-UNK | kein Routen-/Render-Log → `instrument_missing` |

**Abgrenzung M17:** M17 = Job zu früh / partial / dupliziert. D3 = HUD. Ein korrekter Job kann trotzdem SC-LIVE sein, wenn die UI vor Auflegen rendert. Ein verspäteter Job kann SC-POST sein.

**Unit:** Session.

**Instrument:** Route + erstes Score-Render-Event. Deterministisch. HEAD ohne Event: SC-UNK, nicht „0 % Live“.

**Bericht:** Zähler. SC-LIVE oder SC-PREVIEW = Methoden-BLOCK für Trainee-Noten dieser Session (Note ungültig als Diagnose), kein C0.

**Woche 1:** Protokoll. Ist-Stand `/auswertung` nach Call ist `PLAUSIBEL` SC-POST, nicht `VERIFIZIERT` ohne Render-Log.

**Verboten:** Live-HUD „zum Messen“; Preview als Fairness; SC-POST-Rate als Qualität.

### D4 / M24 — Feedback-Last (Careertrainer-Stil, nicht 70/30-Note)

**Fremd:** Careertrainer-Stilwortlaut + Footer-Karte: ein Beleg, ein nächster Schritt. Gong: eine Note, ein Spotlight. Hyperbound-Karten 1–5: ein Fokus, ein Zitat, eine Stärke, ein Fix, Repeat. Nicht 70 % Anerkennung als Quote.

**Konstrukt C17 — die erste Debrief-Fläche trägt genau einen Hebel.**

Gezählt wird die **primäre Fläche** (Kicker Stärke / Schlüsselmoment / Nächstes Mal), nicht der Details-Akkordeon mit Dimension-`ScoreCard`s. EvaluationView zeigt beides — D4 darf den Akkordeon nicht als Last-Fail werten, sonst failt der Ist-Stand per Konstruktion.

| Code | Beobachtung |
|---|---|
| FL-1-1 | genau 1 Stärke + 1 Fix + 1 primärer Moment, oder N/A erklärt |
| FL-OVER | >1 primärer Fix **oder** Radar **oder** 0–10-Galerie als Headline |
| FL-MIX | 70/30-Gewicht, Szenario×Kompetenz-Komposit, oder fremde % als Headline |
| FL-EMPTY | weder Stärke noch Fix, ohne N/A |
| FL-POS70 | Copy oder Zähler „70 % positiv“ / Anerkennungsquote ohne Anker |

`keyMoment.counterfactual` gehört zum **einen** Fix-Block, nicht zu einem zweiten Moment.

**Unit:** Session / erste Debrief-Ansicht.

**Instrument:** Payload-Zählung, deterministisch.

**Bericht:** Zähler. Kein Last-Score. Kein „Cognitive-Load-MOS“.

**Woche 1:** Zählung auf vorhandenen Auswertungen. Deskriptiv.

**Verboten:** FL-1-1 als Gate A oder Lernbeweis; 70/30-Formel „einführen, damit D4 grün wird“; Isolation (keine Stärke) als Tugend.

### D5 / M25 — Moment ≠ Outcome (Gong-Labs-Lehre × Hyperbound-Ehrlichkeit)

**Fremd:** Gong 300M koppelt Opener-Moment an Meeting-Set — das stehlen wir **nicht** als Formel; wir stehlen die **Trennung**, die ihre eigenen Updates erzwingen (Cold ≠ Discovery, 2018 ≠ 2024). Hyperbound: Practice-Score ≫ Real-Score ⇒ Rubrik gelernt, nicht Transfer. Careertrainer: Repeat derselben Situation, nicht neue Note aus Close.

**Konstrukt C18 — der Moment und das Gesprächsende sind zwei Spalten.**

| Spalte | Werte | Darf nicht |
|---|---|---|
| `moment_state` | PRESENT \| ABSENT \| N/A | aus Hangup oder Close abgeleitet werden |
| `call_end` | die drei sichtbaren Enden (A03) bzw. M15-Klassen, deskriptiv | als Trainee-Note oder Gong-Set-Rate |
| `attempt` | FIRST \| REPEAT-SAME (`scenario_id` + dasselbe Moment-Label) | unbegrenztes Repeat als n |
| `corpus` | DRILL \| REAL | REAL ohne echte Fremdcalls |

**REAL:** in Gate A `instrument_missing`. Keine Fake-Gap 0 %. Das **ist** der Hyperbound-Steal: fehlende echte Calls sichtbar lassen.

**REPEAT-SAME:** zweite Session, gleiches Szenario, gleicher Moment. Getrennt berichten. Kein „besser“ ohne A08-Protokoll, Dual-Kodierung und AC1. C3/M10 bleibt DEFER. D5 erzeugt **keine** Transfer-Zahl.

**Unit:** Session in der Kreuztabelle. Leere Zellen ausweisen.

**Instrument:** Felder am Snapshot. Ohne Moment-Label: `moment_state` = UNK, Tabelle nicht füllen.

**Bericht:** n je Zelle. Kein φ, kein Odds Ratio, kein Win-Rate-Headline in Woche 1 (n und Shift unbekannt).

**Woche 1:** Schema + leere Tabelle. Keine Prozent aus n=3 Repeats.

**Verboten:** Gong-Set-Rate, Talk-Ratio-Ampel, 2M-hours-Power-Rechnung, Careertrainer-70/30-Mix, REPEAT-SAME = Lernbeweis (CL-18 analog), FIRST und REPEAT in einer Rate.
