# Telefoncoaching Entwicklerteam v3

Dieses Paket ist die arbeitsfähige Rollenstruktur für Entwicklung, Prüfung und Weiterentwicklung des KI Telefoncoachings.

## Chats

1. `00_Projektleitung.md`
2. `01_Systemarchitektur_CTO.md`
3. `02_Produktleitung.md`
4. `03_Conversation_UX.md`
5. `04_Frontend.md`
6. `05_Backend_Daten.md`
7. `06_Voice_Realtime_Audio.md`
8. `07_Applied_AI.md`
9. `08_Trainingsdesign.md`
10. `09_Evaluation_Datenqualitaet.md`
11. `10_Plattform_SRE.md`
12. `11_Governance_Security_Recht.md`
13. `12_Quality_Cost.md`
14. `13_Character_Psychology.md`
15. `14_Voice_Performance_Prosody.md`

Jeder Fachchat enthält eine ausführende Rolle A und einen unabhängigen Gegenprüfer K. Der Gegenprüfer muss dieselbe Arbeit anhand anderer Kriterien angreifen, darf aber keine Probleme erfinden. Eine Freigabe ist nur mit reproduzierbarem Nachweis erlaubt.

## Start

1. Lege für jede Datei `00` bis `14` einen eigenen Chat an.
2. Kopiere den vollständigen Dateiinhalt als erste Nachricht.
3. Gib jedem Chat zusätzlich `TEAM_KERNEL.md`, `CHANGE_ROUTER.md`, `CHATVERLAUF_PROTOKOLL.md` und nur die für seinen Auftrag erforderlichen Verträge oder Dateien.
4. Neue Sprachbefehle beginnen im Projektleiter Chat.
5. Der Projektleiter erstellt eine Change Card und ruft nur die betroffenen Rollen auf.

## Verbindliche Reihenfolge

`Auftrag -> Impact Analyse -> kleinster sicherer Patch -> gezielte Tests -> Gegenprüfung -> Übergabe -> Entscheidung`

## Kanonische Grundsätze

- Audio zuerst. Keine Avatare im Produktkern.
- Role Generator, Role Player, State Engine und Evaluator bleiben informationell getrennt.
- Charakterrealismus und Stimmrealismus sind eigene Disziplinen.
- Anbieter und Modelle werden über Benchmarks gewählt, nicht über Werbung.
- Keine Qualitäts- oder Rechtsgarantie ohne Nachweis.
- Keine Bewertung von Informationen, die dem Nutzer nicht zugänglich waren.
- Maximale relevante Produktqualität pro Euro, Token und Entwicklungsstunde.
- Keine Repository Vollscans ohne dokumentierten Grund.

## Dateien

- `TEAM_KERNEL.md`: gemeinsame Arbeits- und Qualitätsregeln.
- `CHANGE_ROUTER.md`: gezielte Änderungen aus Sprachbefehlen.
- `CHATVERLAUF_PROTOKOLL.md`: verpflichtender Dialog zwischen A Rolle und Gegenprüfer.
- `ROLE_INDEX.md`: Zuständigkeiten, Übergaben und Konfliktregeln.
- Rollenfiles `00` bis `14`: direkt einsetzbare Chat Prompts mit Ausbildung und Prüfung.
